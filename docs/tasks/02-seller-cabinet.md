# Кабинет продавца

Продавец получает роль `BUYER + SELLER` непосредственно при регистрации. Он может создавать товары, редактировать их, пополнять остаток, включать и отключать показ в каталоге.

Все изменяющие методы проверяют роль и `sellerId`. Загрузка товара для изменения использует блокировку, чтобы одновременное пополнение и редактирование не потеряли данные.

Доступные страницы:

- `/seller/account` — собственные товары;
- `/seller/products/new` — новый товар;
- `/seller/products/{id}/edit` — редактирование;
- `/workspace/seller/orders` — оплаченные части заказов;
- `/workspace/seller/orders/{partId}` — состав и обработка своей части.

Финансы, комиссия, модерация и аналитика продавца не входят в MVP.
