# MarketFlow: текущий порядок работ

Завершён синхронный MVP:

1. корзина;
2. создание заказа со снимками товаров;
3. атомарная тестовая оплата;
4. разделение заказа по продавцам;
5. обработка, отправка и подтверждение получения;
6. Spring Security, роли, сессии и CSRF;
7. unit-, MVC-, repository- и PostgreSQL-тесты.

Активный следующий этап:

1. [RabbitMQ и события](10-rabbitmq-events.md);
2. повторная проверка тестов и документации;
3. Docker/CI;
4. Redis только при необходимости кеширования каталога.

Старые технические задания по комиссии, кошелькам, возвратам и административным кабинетам удалены из рабочей версии. Они находятся в полной резервной копии проекта.
