# Проверка MarketFlow MVP

Обязательные проверки:

- unit-тесты сущностей и сервисов;
- repository-тесты на H2;
- MockMvc-тесты MVC и REST;
- Spring Security: сессия, роли, CSRF, 401/403;
- PostgreSQL: чистое применение V1–V12 и обновление V11 → V12;
- идемпотентная повторная оплата;
- параллельная покупка последней единицы товара;
- откат карты, статуса и ранних списаний при нехватке следующего товара;
- заказ с двумя продавцами и запрет доступа к чужой части;
- завершение общего заказа только после получения всех частей.

PostgreSQL-тесты должны работать только с отдельной тестовой базой. Перед применением V12 к существующей рабочей базе создаётся резервная копия.

После успешной проверки этап фиксируется отдельным Git-коммитом. Следующими независимыми работами могут быть RabbitMQ, Docker и CI.
